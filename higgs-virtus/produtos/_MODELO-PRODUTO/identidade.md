# 🎯 Produto: _MODELO (duplique esta pasta e renomeie para o seu produto)_

Define a **identidade visual** que toda arte deste produto deve seguir.
Para cadastrar um produto novo: copie a pasta `_MODELO-PRODUTO/`, renomeie
(ex.: `produtos/mentoria-x/`) e preencha os assets abaixo.

## Assets de identidade

| Asset | Pasta | Obrigatório | Status |
|-------|-------|-------------|--------|
| 🎨 Paleta de cores | `paleta/` | ✅ 1 imagem | ⬜ |
| 🔤 Fonte / tipografia | `tipografia/` | ✅ 1 imagem | ⬜ |
| 🖼️ Refs de diagramação/composição | `referencias/` | ✅ 2 a 5 imagens | ⬜ |
| 🏷️ Logo do produto | `logo/` | ⬜ Opcional | ⬜ |
