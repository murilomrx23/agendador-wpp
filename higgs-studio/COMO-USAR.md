# 🎨 Higgs Studio — Como pedir suas artes

Guia rápido para o time solicitar criativos de **ISD** e **PROTAGON**. A identidade
de cada produto (paleta, tipografia, fidelidade de rosto dos experts, regras de
composição) já está embutida na skill e é aplicada **automaticamente** — você só
precisa dizer o essencial.

## Como funciona (o fluxo)
1. **Você pede** — produto + expert + as copies (ou o link do Google Doc).
2. **Gero a 1:1** — a 1ª lâmina de um estilo novo sai sozinha para validação.
3. **Você valida** — confere texto, rosto e identidade no widget do Higgsfield.
4. **Escalo o lote** — gero as demais copies em 1:1.
5. **Reframe & entrega** — cada arte vira **9:16 (Stories)** e **4:5 (Feed)**.

## 3 formas de pedir

### 1) Comando de 1 linha (mais simples)
```
Higgs Studio: ISD, expert Wendell — gera os 10 estáticos do doc [ISD] Remarketing
```
```
Gera no Higgs 5 posts do PROTAGON com a Karina sobre [tema]
```

### 2) Ficha rápida (recomendado para lote)
```
🎨 HIGGS STUDIO — GERAR ARTES
PRODUTO: ISD              (ou PROTAGON)
EXPERT: WENDELL           (WENDELL | KARINA | WENDELL E KARINA | LIVRE)
VARIANTE: DARK            (DARK | LIGHT — opcional)
FORMATOS: 1:1, 9:16, 4:5  (opcional; esse é o padrão)
COPIES:
- <cole a copy 1 aqui>
- <copy 2>
- <copy 3>
```

### 3) Só apontar a fonte das copies
```
Higgs Studio: ISD + Wendell. Copies no Google Doc "[ISD] Remarketing" (Ads 01–10). Gera tudo.
```

**Palavras-gatilho:** "Higgs Studio", "gerar artes", "gera no Higgs", "criativo/post/campanha ISD ou PROTAGON".

## O que já é automático (não precisa mandar)
- Paleta oficial de cada produto (ISD `#FF7000` preto/branco · PROTAGON azul-marinho + dourado)
- Contraste roupa × fundo (fundo escuro → roupas claras) + traje elegante
- ISD: efeito 3D escovado só no logo; copies brancas com destaque laranja
- Tipografia: caixa alta só na headline; apoios em caixa baixa
- Variação de pose/enquadramento/roupa por lâmina
- Fidelidade de rosto dos experts + personagem dominante (40–60%)
- Variantes DARK / LIGHT e reframe 9:16 + 4:5

## Antes de começar
- Confirme que **Higgsfield** e **Google Drive** estão conectados na conversa.
- **1 copy = 1 arte.** Separe as copies em blocos/linhas.
- Para um **estilo novo**, valide a 1ª 1:1 antes de escalar o lote (economiza créditos).
